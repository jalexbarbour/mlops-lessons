Toolchain

Chosen for a 16 GB Apple Silicon machine, where unified memory efficiency matters more than ecosystem breadth.

LayerToolWhy
Training runtime MLX (mlx-lm) Apple's own framework, built for unified memory — no CPU↔GPU copies, the most headroom per GB on this hardware.
Env / deps uv Pins the Python version and dependency graph in a lockfile — reproducibility starts here.
Fine-tuning method LoRA Full fine-tuning (plus optimizer state) doesn't fit comfortably in 16 GB; LoRA trains ~0.2% of parameters and fits easily.
Experiment tracking MLflow (local, sqlite) Logs hyperparameters, loss curves, and the adapter artifact per run, so fine-tunes are comparable instead of lost.
Data versioning jsonl + git LoRA datasets are small; no need for DVC-scale tooling yet.
Serving mlx_lm.server OpenAI-compatible local endpoint — closes the loop from fine-tune to something callable.

Pipeline

  1. Install dependencies

    Creates a .venv pinned to Python 3.12 and installs mlx-lm + mlflow.

    uv sync

  2. Generate the dataset

    Deterministic, seeded synthetic data: 200 train / 30 valid / 30 test examples.

    uv run python data/generate_dataset.py

  3. Fine-tune with tracking

    LoRA fine-tune via mlx_lm.lora.train_model. A custom MLflowCallback hooks the trainer's on_train_loss_report / on_val_loss_report events and logs params, per-step metrics, and the adapter as an MLflow artifact.

    uv run python train.py

  4. Evaluate

    Scores base vs. fine-tuned on the held-out test set: exact match and per-field accuracy, both logged to the same MLflow experiment.

    uv run python eval.py

  5. Fuse and serve

    Merges the LoRA adapter into the base weights, then serves it locally behind an OpenAI-compatible endpoint.

    uv run python -m mlx_lm fuse \
  --model mlx-community/Qwen2.5-1.5B-Instruct-4bit \
  --adapter-path adapters --save-path fused-model

uv run python -m mlx_lm server --model fused-model --port 8765

Inspect experiment tracking

Every run — training and eval — is queryable in the MLflow UI.

uv run mlflow ui --backend-store-uri sqlite:///mlflow.db
